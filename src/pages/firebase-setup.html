🔥 Configuration Firebase

Suivez ces étapes pour activer la messagerie en temps réel avec Firebase

1
Créer un compte Firebase

  1. Allez sur https://console.firebase.google.com
  2. Connectez-vous avec votre compte Google
  3. Cliquez sur "Créer un nouveau projet"
  4. Donnez un nom (ex: "EcolePasDirecte")
  5. Acceptez les conditions et cliquez "Continuer"

2
Récupérer la configuration

  1. Dans la console Firebase, cliquez sur ⚙️ Paramètres (en haut à gauche)
  2. Allez à l'onglet "Général"
  3. Scroll vers le bas et cherchez "Vos applications"
  4. Si aucune app web n'existe, créez-en une (cliquez sur l'icône </>)
  5. Vous verrez une boîte avec du code qui ressemble à:
    const firebaseConfig = {
    apiKey: "AIzaSyD...",
    authDomain: "votreprojet.firebaseapp.com",
    projectId: "votreprojet",
    storageBucket: "votreprojet.appspot.com",
    messagingSenderId: "000...",
    appId: "1:000...:web:..."
    };
  6. COPIEZ TOUT CE CODE

3
Mettre à jour le fichier de configuration

  1. Ouvrez le fichier firebase-config.js du projet
  2. REMPLACEZ tout le contenu par le code que vous avez copié à l'étape 2
  3. Sauvegardez le fichier (Ctrl+S)
✅ La première partie est terminée!

4
Créer une base de données Firestore

  1. Retournez à la console Firebase (https://console.firebase.google.com)
  2. Dans le menu de gauche, cliquez sur "Firestore Database"
  3. Cliquez sur "Créer une base de données"
  4. Choisissez votre région (ex: europe-west1 pour l'Europe)
  5. TRÈS IMPORTANT: Choisissez "Démarrer en mode test"
  6. Cliquez "Créer"
⚠️ Mode test: Les données sont publiques mais c'est parfait pour tester. Nous allons sécuriser après.

5
Configurer les règles de sécurité

  1. Dans Firestore, allez à l'onglet "Règles"
  2. Remplacez les règles par le contenu du fichier firestore.rules, puis cliquez sur "Publier".
  3. Pour autoriser un professeur, ouvrez son document dans users et définissez role à prof. Les nouveaux comptes reçoivent le rôle eleve. À sa première connexion, un professeur initialise aussi l'index des noms des anciens comptes.
✅ Les élèves consultent leurs données; seuls les comptes prof peuvent ajouter des devoirs et des mots au carnet.

6
Tester la messagerie

  1. Ouvrez messages-firebase.html dans votre navigateur
  2. Connectez-vous avec votre nom
  3. Ouvrez un autre onglet et connectez-vous avec un nom différent (ex: "Alex")
  4. Dans le premier onglet, envoyez un message
  5. Regardez le deuxième onglet - le message apparaît EN TEMPS RÉEL ✨
✅ Félicitations! La messagerie fonctionne!

❓ Questions Fréquentes

Où je dois mettre ma clé API Firebase? ▼
Dans le fichier firebase-config.js. C'est pas grave que les autres voient votre clé API - les données sont protégées par les règles Firestore.
Les messages ne s'envoient pas, que faire? ▼
  1. Appuyez sur F12 et allez à l'onglet "Console"
  2. Cherchez les messages d'erreur en rouge
  3. Vérifiez que votre configuration Firebase est correcte
  4. Vérifiez que Firestore est bien créé
Pourquoi je dois utiliser "Mode test"? ▼
Le mode test vous permet de tester facilement sans authentification. Pour la production (quand vous mettez en ligne), vous devez ajouter une vraie authentification et de vraies règles de sécurité.
Comment je simule deux utilisateurs? ▼
  1. Ouvrez deux onglets du navigateur
  2. Dans chaque onglet, connectez-vous avec des noms différents
  3. Envoyez des messages d'un onglet à l'autre
  4. C'est magique! Les messages s'envoient en temps réel 🚀
Est-ce que ma configuration Firebase est sécurisée? ▼
En mode test: NON - C'est pour le développement seulement. Les données sont publiques. Pour la production, activez Firebase Authentication et écrivez de vraies règles de sécurité.
